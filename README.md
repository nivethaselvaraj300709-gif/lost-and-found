# Lost and Found Management System

A web-based platform designed to simplify the process of reporting, tracking, and recovering lost and found items within a college campus.

## 1. Project Overview

The **Lost and Found Management System** provides a centralized platform where students can report misplaced belongings and share information about items they have found.

The system aims to improve communication, reduce the effort involved in locating lost belongings, and create a more organized recovery process within the campus environment.

## 2. Problem Statement

Students frequently misplace personal belongings within college premises. Traditional methods of finding these items, such as verbal communication and notice boards, are often inefficient and time-consuming.

This project addresses the problem by providing a digital platform that connects people who have lost items with those who have found them.

## 3. Key Features

- **Lost Item Reporting:** Submit reports with item names, descriptions, and relevant details.
- **Found Item Reporting:** Publish information about items discovered on campus.
- **Item Search:** Search for specific items using keywords.
- **Category Filtering:** Filter listings based on their status.
- **Item Listings:** View reported lost and found items in an organized interface.
- **Responsive Interface:** Access the platform across different screen sizes.
- **Local Data Storage:** Store listings using browser LocalStorage.

## 7. Application Workflow

1. Access the Lost and Found platform.
2. Select the appropriate reporting option.
3. Enter the required item information.
4. Submit the item listing.
5. Browse or search existing listings.
6. Identify relevant lost or found item reports.

## 8. Current Implementation

The current version is developed as a frontend web application using HTML, CSS, and JavaScript.

Item information is stored locally in the browser using LocalStorage. A centralized backend and database are not included in the current implementation.
